# Function: getDashboardVersion()

> **getDashboardVersion**(): `string`

Read the version of the dashboard that runs in the page, for a plugin that adapts its behavior to it.

## Returns

`string`

A semantic version, for example `1.4.0`.

## Throws

[DashboardNotFoundError](../classes/DashboardNotFoundError.md) when the dashboard is not loaded in the page.
