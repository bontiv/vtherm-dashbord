# Function: normalizeLanguage()

> **normalizeLanguage**(`tag`): `string`

Compare language tags without regard to case or to the difference between `-` and `_`.

## Parameters

### tag

`string`

A language tag, for example `pt_BR`.

## Returns

`string`

The normalized tag, for example `pt-br`.
